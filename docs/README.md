# Documentación — Simple Bill

Índice maestro de la documentación de este repositorio. Cada documento del repo está enlazado aquí con una línea honesta de qué contiene; un documento sin índice es un documento perdido.

## Cómo se mantiene esta carpeta

- Toda historia que cierra y añade o mueve documentación actualiza este índice en el mismo commit.
- Los estados se declaran como en el README principal: **Construido** · **En desarrollo** · **Diseñado** · **Concepto**, sin mezclarlos.
